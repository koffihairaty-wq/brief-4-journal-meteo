1. **Une fonction que j'ai écrite**, et comment elle marche : 
J'ai écrit la fonction afficherMenu() dans le fichier app.js.
Son rôle est d'afficher les différentes options de mon application dans le terminal : ajouter un relevé, consulter les relevés, effectuer une recherche, trier les données, afficher la synthèse ou quitter le programme.
Cette fonction utilise console.log() pour afficher les choix à l'écran. Elle ne réalise pas directement les opérations : elle présente simplement les possibilités offertes à l'utilisateur.
